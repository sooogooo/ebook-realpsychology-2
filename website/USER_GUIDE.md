# 医美消费心理学网站使用指南

## 概述

欢迎使用医美消费心理学网站！这是一个基于学术研究的综合性平台，提供丰富的数据可视化工具、交互式图表和专业的心理评估工具，帮助用户深入了解医美消费的心理机制。

## 网站结构

### 主要页面

1. **首页 (index.html)** - 网站主入口，包含章节导航和概述
2. **数据可视化 (data-visualization.html)** - 交互式统计图表展示
3. **文化差异比较 (cultural-comparison.html)** - 跨文化心理差异分析
4. **决策树工具 (decision-tree.html)** - 医美决策流程可视化
5. **情绪状态流 (emotional-state-flow.html)** - 消费者情绪变化追踪
6. **多语言测试 (multi-language-test.html)** - 多语言功能测试页面

### SVG插图库

每个章节都配有专业的SVG插图，涵盖：
- 多维视角分析
- 研究方法论
- 心理需求模型
- 决策流程图
- 文化差异对比
- 技术发展时间线
- 未来趋势预测

## 使用指南

### 基本操作

#### 1. 导航网站
- 使用主导航菜单在不同页面间切换
- 点击面包屑导航返回上级页面
- 使用语言切换器更改界面语言

#### 2. 数据可视化
- 选择不同的图表类型查看数据
- 使用筛选器查看特定人群数据
- 点击导出按钮下载图表数据
- 鼠标悬停查看详细数据提示

#### 3. 文化比较
- 选择两个文化进行对比
- 查看文化差异矩阵
- 阅读文化适应性建议
- 探索相关案例研究

#### 4. 决策树
- 从起始节点开始决策流程
- 根据个人情况选择路径
- 查看每个节点的详细信息
- 记录决策过程和结果

#### 5. 情绪追踪
- 选择要追踪的情绪维度
- 查看不同时间点的情绪状态
- 了解情绪变化的原因和建议
- 导出个人情绪报告

### 数据管理

#### 导出数据
1. 在数据可视化页面选择导出格式
2. 点击"导出数据"按钮
3. 选择JSON、CSV或Excel格式
4. 文件将自动下载到本地

#### 导入数据
1. 点击"导入数据"按钮
2. 选择本地数据文件
3. 系统自动验证和处理数据
4. 图表将更新显示新数据

#### 数据刷新
1. 点击"刷新数据"按钮
2. 系统生成新的模拟数据
3. 所有图表自动更新
4. 数据状态面板显示更新信息

### 语言切换

#### 切换语言
1. 点击页面右上角的语言选择器
2. 选择目标语言
3. 界面文本立即更新
4. 语言偏好自动保存

#### 添加新语言
系统支持扩展新语言，如需添加：
1. 准备语言翻译文件
2. 配置语言支持信息
3. 更新多语言系统
4. 测试翻译准确性

## 常见问题

### 技术问题

#### Q: 图表无法显示怎么办？
A: 请检查：
- 浏览器是否支持JavaScript
- 网络连接是否正常
- 是否启用了广告拦截器
- 尝试刷新页面

#### Q: 数据导出失败怎么办？
A: 可能的原因：
- 浏览器不支持文件下载
- 数据量过大导致超时
- 文件格式不支持
- 尝试使用不同的浏览器

#### Q: 语言切换不生效？
A: 解决方法：
- 检查JavaScript是否启用
- 清除浏览器缓存
- 确认语言文件加载完成
- 重新加载页面

### 功能问题

#### Q: 如何保存我的数据？
A: 系统支持：
- 本地存储自动保存
- 导出数据到本地文件
- 导入之前保存的数据
- 刷新数据生成新样本

#### Q: 决策树如何使用？
A: 使用步骤：
1. 选择决策类型
2. 从起始节点开始
3. 根据实际情况选择选项
4. 查看最终建议和结果

#### Q: 文化比较如何解读？
A: 解读方法：
1. 选择要对比的文化
2. 查看差异矩阵
3. 阅读详细分析
4. 参考案例研究
