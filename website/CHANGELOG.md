## 已知问题和限制

### 当前版本限制
1. **浏览器兼容性**: 不支持IE浏览器
2. **移动端性能**: 大数据集在移动设备上可能较慢
3. **离线功能**: 需要网络连接
4. **数据存储**: 仅支持客户端存储

### 计划改进
1. **PWA支持**: 离线功能
2. **后端API**: 服务器端数据处理
3. **数据库集成**: 持久化存储
4. **用户认证**: 多用户支持

## 贡献指南

### 开发环境设置
```bash
# 克隆仓库
git clone <repository-url>
cd medical-aesthetics-psychology

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

### 代码规范
- 使用ESLint进行代码检查
- 遵循Prettier格式化规则
- 编写适当的注释
- 提交前进行测试

### 提交规范
```
feat: 新功能
fix: 修复bug
docs: 文档更新
style: 代码格式化
refactor: 代码重构
test: 测试相关
chore: 构建或工具变动
```
