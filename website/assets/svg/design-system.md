# SVG Design System

```css
--text-secondary: #6c757d

--border-light: #dee2e6
```

## Design Principles
- **Minimalist**: Clean, uncluttered designs with plenty of whitespace
- **Elegant**: Sophisticated aesthetics with attention to detail
- **Consistent**: Unified visual language across all illustrations
- **Thin Lines**: 1-2px stroke width for delicate appearance
- **Geometric**: Simple shapes and forms for modern look

## Icon Specifications
- ViewBox: "0 0 24 24" for small icons
- Stroke width: 1.5px
- Fill: none (outline style)
- Consistent corner radius: 2px

## Illustration Specifications
- ViewBox: "0 0 400 300" for concept illustrations
- ViewBox: "0 0 800 200" for chapter headers
- Stroke width: 1-2px
- Limited color palette (2-3 colors per illustration)
- Subtle gradients for depth

## Animation Guidelines
- Gentle transitions (0.3s duration)
- Smooth easing functions
- Purposeful animations that enhance understanding
- No distracting or excessive animations
