# 医美消费心理学 - 优雅静态网站

## 项目简介
《这才是医美消费心理学》是一个中文学术书籍项目，包含10个核心章节和2个研究文档，总计约50万字。

## 网站特色
- **优雅设计**: 采用简约配色、细线条和细字体的优雅设计风格
- **响应式布局**: 完美适配桌面端和移动端设备
- **优化的SVG插图**: 115张专业SVG插图，采用优雅的视觉设计
- **流畅体验**: 平滑的动画效果和用户友好的交互设计

## 设计理念
- **简约美学**: 使用简洁的线条和留白，营造优雅的阅读体验
- **字体优化**: 采用Georgia和Noto Serif字体，确保中文显示效果
- **色彩搭配**: 使用柔和的色彩系统，减少视觉疲劳
- **响应式设计**: 完美适配各种设备尺寸

## 使用方法
1. 将整个`publishstatic`文件夹复制到Web服务器
2. 通过浏览器访问`index.html`即可开始浏览
3. 所有链接均为相对路径，支持离线浏览

## 技术特性
- **纯静态**: 无需数据库或服务器端支持
- **SEO友好**: 完整的meta标签和结构化数据
- **性能优化**: 最小化的CSS和JavaScript
- **可访问性**: 遵循Web可访问性标准
