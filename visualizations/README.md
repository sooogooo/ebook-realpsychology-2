# Medical Aesthetics Consumer Psychology - Mermaid.js Visualizations

This directory contains comprehensive Mermaid.js visualizations for the medical aesthetics consumer psychology book project. These diagrams are designed to illustrate complex psychological concepts, decision-making processes, and stakeholder relationships in a clear, academic format.

## Visualization Categories

### 1. Decision-Making Processes
- Consumer journey flowcharts
- Information search behaviors
- Risk assessment workflows
- Decision bias correction processes

### 2. Stakeholder Relationships
- Multi-party ecosystem maps
- Role interaction diagrams
- Communication flow patterns
- Value exchange networks

### 3. Psychological Frameworks
- Motivation type classifications
- Body image disorder frameworks
- Anxiety assessment models
- Satisfaction determination factors

### 4. Research Methodologies
- Study design workflows
- Data analysis processes
- Mixed-method approaches
- Quality assurance frameworks

### 5. Assessment Tools
- Evaluation process flows
- Scoring system diagrams
- Multi-dimensional assessments
- Tracking and monitoring charts

## Implementation Guide

Each visualization is provided in three formats:
1. **Mermaid Code** - For direct integration with Mermaid.js
2. **HTML Template** - Complete HTML with Mermaid integration
3. **SVG Export** - Static image versions for print

## Styling System

All visualizations use a consistent color scheme and styling:
- **Primary Blue**: #2E86AB (Professional, Trustworthy)
- **Secondary Purple**: #A23B72 (Psychology, Healthcare)
- **Accent Green**: #8FD14F (Growth, Positive Outcomes)
- **Warning Orange**: #F18F01 (Risk, Caution)
- **Neutral Gray**: #4A4A4A (Text, Professional Content)

## Usage Instructions

1. Copy the Mermaid code directly into any Mermaid-compatible platform
2. Use HTML templates for web integration
3. Export SVG versions for print publications
4. Customize colors and styles using the provided CSS variables

## Technical Requirements

- Mermaid.js 8.0+
- Modern browser with ES6 support
- For web integration: HTML5, CSS3
- Export capabilities require Mermaid CLI or similar tools
